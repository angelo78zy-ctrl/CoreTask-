# 📋 CoreTask

**Recuerda. Organiza. Logra.**

App de tareas con recordatorios para Android. Incluye a Coco, tu mascota, con racha, XP, niveles, logros y estadísticas semanales y mensuales.

## 📲 Descargar

👉 [Descargar la última versión (APK)](https://github.com/angelo78zy-ctrl/CoreTask-/releases/latest)

En esa página baja a **Assets** y toca **CoreTask.apk**.

## Cómo instalar

1. Descarga `CoreTask.apk`.
2. Ábrelo. Si Android lo pide, permite «Instalar apps de esta fuente».
3. Si Play Protect avisa, toca «Instalar de todos modos».
4. Abre CoreTask y acepta las notificaciones.

## Funciones

- Recordatorios con notificación, incluso con la app cerrada
- Categorías, prioridades y tareas repetidas
- Racha, XP, niveles y logros
- Inicio de sesión con Google para guardar tu progreso
